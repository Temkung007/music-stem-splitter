# งานพร้อมกันตามสเปค — Worker 1.5.0

เปิดการรับงานและการตั้งค่า → งานพร้อมกัน เลือก “อัตโนมัติตามสเปค” หรือจำนวนงานที่ต้องการ ไม่ต้องติดตั้งแอปซ้ำบน Mac เดียว เครื่องยังใช้ worker ID/token เดียว แต่แต่ละช่องทำงานมี process, model, heartbeat, lease, log และ progress แยกกัน

## เพดานที่ตั้งไว้

- RAM ต่ำกว่า 12 GB หรือ CPU น้อยกว่า 8 logical cores: 1 งาน
- RAM 12–ต่ำกว่า 24 GB: สูงสุด 2 งาน
- RAM 24–ต่ำกว่า 48 GB: สูงสุด 3 งาน
- RAM 48 GB ขึ้นไป: สูงสุด 4 งาน
- GPU Apple รุ่นพื้นฐาน (ไม่มี Pro/Max/Ultra): จำกัดไม่เกิน 2 งาน แม้ RAM สูงกว่า

นี่คือเพดานอนุรักษนิยมของแอป ไม่ใช่จำนวนที่รับรองว่าเร็วที่สุดสำหรับทุกเพลง GPU และ unified memory ใช้ร่วมกัน ไม่ได้เพิ่มความเร็วเป็นเท่าตัวตามจำนวนงาน

Auto เลือกตามเพดานนี้และตรวจสถานะ RAM ทุกประมาณ 5 วินาที หาก memory pressure เตือนหรือ free percentage ต่ำกว่า 25 จะลดการรับงานใหม่เหลือ 1; หากวิกฤตหรือต่ำกว่า 10 จะพักรับงานใหม่ เมื่อ RAM กลับมาปกติรออย่างน้อย 20 วินาทีจึงเพิ่มกลับ การลดจำนวน/กดพักไม่หยุดงานที่กำลังทำ ให้จบแล้วค่อยใช้จำนวนใหม่ หากอ่านสถานะ RAM ไม่ได้ ใช้ 1 งาน

หยุด coordinator หรือไม่มีการอัปเดต pool-control เกิน 15 วินาที ช่องงานจะหยุดรับงานใหม่เพื่อไม่ให้ process ที่ค้างรับงานต่อเอง

## ความถูกต้องของคิวและ cache

เซิร์ฟเวอร์จองงานและตรวจเพดานทั้งเครื่อง/ช่องงานใน transaction เดียว ไม่แจกสองงานให้ช่องเดียวกัน ลูกค้าเก่ายังทำครั้งละหนึ่งงาน ไม่มีการเปลี่ยน schema DB

แยกสถานะ/log/runtime helper ตามช่อง แต่ใช้ผลลัพธ์ cache ที่ตรวจ SHA ร่วมกันและมี file lock ต่อ job การกวาด cache จะข้ามงานของช่องอื่นที่ยังใช้งานอยู่ แต่ละ job ใช้ lease แยก จึงต่ออายุหรือยกเลิกงานหนึ่งโดยไม่กระทบอีกงาน

หน้าควบคุมแสดงความคืบหน้าแต่ละงาน พร้อมจำนวนงานที่กำลังทำในแต่ละเครื่อง คุณภาพ AI เดิม: เสียงร้อง Kim Vocal 2 และ 4 แทร็ค HTDemucs FT เมื่อเลือกละเอียด

## ผลวัดบนเครื่องจริง

Mac Apple M5, RAM 16 GB: เพดาน 2 งาน ใช้คลิปเสียงร้อง 24 วินาที จำนวน 2 งาน ด้วย Kim Vocal 2 และ engine ที่ warm แล้ว

- ทำทีละงาน: 21.62 วินาทีรวม
- ทำพร้อมกัน: 20.18 วินาทีรวม
- throughput 1.071 เท่า ประมาณ 7% เพิ่มขึ้นใน trial นี้ ไม่รวมการรับส่งไฟล์
- รูปทรง/จำนวน sample ตรงกัน ความต่างเอาต์พุตหลังคืน gain ไม่เกินประมาณ 1 PCM16 quantization step ไม่ลดรุ่นโมเดล

เป็นการวัดครั้งเดียวกับคลิปนี้ ไม่ใช่ SLA หรือหลักฐานว่าทุกเพลงจะเร็วขึ้น การแยก 4 แทร็คยาวหลายเพลงอาจมีผลต่างจากนี้ เครื่อง M5 16 GB ตั้ง Auto ได้ 2 งาน และลดเป็น 1 เองได้หากต้องการตอบสนองเร็วต่อเพลง
