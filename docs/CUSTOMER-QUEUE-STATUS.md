# สถานะคิวสำหรับผู้ใช้

หน้าเว็บแสดงข้อความสั้น ๆ ว่ารอคิว กำลังแยกเสียง หรือเตรียมไฟล์ดาวน์โหลด
ถ้ามีงานรอตั้งแต่ 3 งานขึ้นไป แจ้งว่ามีงานรอประมวลผลจำนวนมากและอาจใช้เวลาสักครู่
ไม่แสดงตัวเลขลำดับคิว จำนวนงาน เวลา หรือรายละเอียดสัญญาณเครื่องให้ลูกค้า

กำลังประมวลผลแสดงเปอร์เซ็นต์ตามงานจริง และเชื่อมต่อใหม่อัตโนมัติเมื่อเน็ตขาด
รองรับไทยและอังกฤษ ข้อมูลคิวเบื้องหลังและหน้าควบคุม Worker ยังทำงานตามเดิม
