วิธีตั้งค่าใน rekordbox

1
เปิด rekordbox XML ในการตั้งค่า

ไปที่ Preferences > View > Layout แล้วติ๊กถูกที่ช่อง rekordbox xml

2
เลือกไฟล์ฐานข้อมูล STEMORA

ไปที่ Preferences > Advanced > Database ในช่อง rekordbox xml ให้กด Browse แล้วเลือกไฟล์:

~/Music/STEMORA/rekordbox.xml
3
พร้อมเล่นบน CDJ / Controller

ในแถบซ้ายของ rekordbox จะมีหัวข้อ rekordbox xml > STEMORA ลากเพลงลง Deck เล่นได้ทันที!
